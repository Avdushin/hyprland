# Key bindings

| Shortcut | Action |
|---|---|
| `Super + Enter` | Ghostty |
| `Super + B` | Default browser |
| `Super + E` | Thunar |
| `Super + D` | Rofi |
| `Super + Shift + D` | Wofi |
| `Alt + V` | Clipboard history |
| `Super + X` | Power menu |
| `Super + L` | Lock |
| `Super + W` | Random wallpaper |
| `Super + Shift + W` | Next favorite wallpaper |
| `Super + P` | Toggle Waybar |
| `Super + Shift + R` | Reload Hyprland |
| `Super + Shift + S` | Select screenshot area/window |
| `Super + 1…9` | Switch workspace |
| `Super + Shift + 1…9` | Move window silently |
| `Super + arrows` | Focus window |
| `Super + Shift + arrows` | Move window |
| `Super + R` | Resize submap |
| `Super + Q` | Close window |
| `Super + F` | Fullscreen |
| `Super + Space` | Toggle floating |
