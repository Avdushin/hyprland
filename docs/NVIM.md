# Neovim / NvChad

![demo-1](./imgs/nvim/1.jpg)

![demo-2](./imgs/nvim/2.jpg)

![demo-3](./imgs/nvim/3.jpg)

В сборку входит конфигурация Neovim на базе **NvChad v2.5** с темой
**Fog & Ember**, прозрачным интерфейсом, LSP, форматированием, поиском в
текущем файле, поиском и заменой по проекту, мультикурсором, постоянными
терминалами, поддержкой русской раскладки и быстрыми заметками.

## Установка и запуск

Конфигурация устанавливается в:

```text
~/.config/nvim
```

Дополнительный launcher:

```text
~/.local/bin/nvchad
```

Он удаляет переменную `NVIM_APPNAME` перед запуском, поэтому использует
основной профиль `~/.config/nvim`.

Запуск:

```bash
nvim
```

или:

```bash
nvchad
```

При первом запуске `lazy.nvim` автоматически скачает плагины.

Управление плагинами:

```vim
:Lazy
```

Установка и обновление:

```vim
:Lazy sync
```

## Что входит в конфигурацию

- NvChad и Base46;
- тема Fog & Ember и альтернативная тема Gruvbox;
- Telescope для поиска файлов, текста и буферов;
- NvimTree для дерева файлов с названием корня текущего проекта;
- настраиваемый statusline с режимом, файлом, Git-веткой, диагностикой,
  языком, позицией курсора и названием проекта;
- Conform для форматирования;
- встроенный LSP-клиент Neovim;
- Grug FAR для поиска и замены;
- `render-markdown.nvim` для Markdown;
- `image.nvim` для изображений в Markdown;
- `nvim-surround` и Sublime-подобное оборачивание выделенного текста;
- поддержка команд и пользовательских Ctrl-сочетаний на русской раскладке;
- `vim-visual-multi` для нескольких курсоров;
- Tabnine и стандартное дополнение NvChad;
- постоянный нижний и плавающий терминалы с сохранением shell-сессии;
- стандартный правый терминал NvChad;
- Draft, Note, Notes, Scratch и ClipEdit.

## Обозначения клавиш

| Обозначение | Значение |
|---|---|
| `<leader>` | `Space` |
| `<localleader>` | обратный слеш `\` |
| `Ctrl` | клавиша Control |
| `Alt` | клавиша Alt |
| `Shift` | клавиша Shift |
| Normal | обычный режим Neovim |
| Insert | режим ввода текста |
| Visual | режим выделения |
| Terminal | режим терминала |

Последовательности с `leader` нажимаются по очереди. Например:

```text
Space → n → d
```

Удерживать `Space` не требуется.

## Пользовательские сочетания

### Основные действия

| Сочетание | Режим | Действие |
|---|---|---|
| `;` | Normal | открыть командную строку Neovim |
| `jk` | Insert | выйти в Normal mode |
| `gd` | Normal | перейти к определению символа через LSP |
| `Ctrl+F` | Normal, Insert или Visual | найти текст в текущем файле |
| `Ctrl+P` | Normal | найти файл через Telescope и ripgrep |
| `Ctrl+B` | Normal | открыть или закрыть NvimTree |
| `Ctrl+N` | Normal | создать новый пустой буфер |
| `Ctrl+W` | Normal | закрыть текущий буфер-вкладку NvChad |
| `Ctrl+W` | Insert | удалить слово слева от курсора |
| `Ctrl+1` … `Ctrl+9` | Normal | перейти к буферу с соответствующим номером |
| `Space c` | Normal | скопировать относительный путь текущего файла |
| `Space d` | Normal | продублировать текущую строку вниз |
| `Ctrl+Shift+I` | Normal | отформатировать текущий файл |
| `Space ut` | Normal | переключить Fog & Ember и Gruvbox |

`Ctrl+P` включает скрытые файлы, но исключает каталог `.git`.

`Ctrl+W` в Normal mode специально переопределён для закрытия текущего
буфера. В Insert mode сохраняется стандартное поведение Neovim — удаление
слова слева от курсора.

### NvimTree и statusline

В верхней строке NvimTree отображается имя корневой папки текущего проекта,
а не полный абсолютный путь.

Statusline показывает:

```text
MODE  file  Git branch  diagnostics  language  Ln, Col  project
```

Например:

```text
NORMAL  Hero.tsx  v4.3next  clean  TSX  Ln 21, Col 1  avdyushin.ru
```

Элементы statusline:

- текущий режим;
- имя открытого файла;
- активная Git-ветка;
- количество ошибок, предупреждений, подсказок и информационных сообщений;
- `clean`, если к буферу подключён LSP и диагностика пуста;
- язык текущего файла вместо внутреннего имени LSP-сервера;
- текущая строка и столбец;
- имя корня проекта.

Галочка рядом с языком означает, что к текущему буферу подключён LSP-клиент.

### Перемещение строк

| Сочетание | Режим | Действие |
|---|---|---|
| `Ctrl+Shift+Down` | Normal | переместить строку вниз |
| `Ctrl+Shift+Up` | Normal | переместить строку вверх |
| `Ctrl+Shift+Down` | Insert | переместить строку вниз и вернуться в Insert |
| `Ctrl+Shift+Up` | Insert | переместить строку вверх и вернуться в Insert |
| `Ctrl+Shift+Down` | Visual | переместить выделенный блок вниз |
| `Ctrl+Shift+Up` | Visual | переместить выделенный блок вверх |

### Кавычки внутри круглых скобок

Курсор должен находиться внутри круглых скобок.

Исходный текст:

```python
print(hello)
```

| Сочетание | Действие |
|---|---|
| `Space "` | обернуть содержимое скобок в двойные кавычки |
| `Space q` | переключать тип кавычек |

Последовательность:

```text
hello → "hello" → 'hello' → `hello` → "hello"
```

Также установлен `nvim-surround` со стандартными командами:

| Команда | Действие |
|---|---|
| `ys` | добавить окружение |
| `ds` | удалить окружение |
| `cs` | заменить окружение |

### Оборачивание выделенного текста

Выделите текст через `v` или `Shift+V`, затем нажмите один из символов:

```text
"  '  `  (  )  [  ]  {  }  <  >
```

Исходный текст остаётся выделенным после операции, поэтому повторные нажатия
последовательно добавляют новые уровни окружения.

Пример:

```text
hello world
"hello world"
""hello world""
"""hello world"""
```

Для скобок:

```text
hello
(hello)
((hello))
(((hello)))
```

`v` выделяет точный диапазон символов. `Shift+V` включает построчное
выделение.

Если через `Shift+V` выбрана одна строка, внешние пробелы не включаются
в окружение:

```text
    hello world
```

превращается в:

```text
    "hello world"
```

Если выбрано несколько строк, обрамление располагается на отдельных строках.
Последовательные нажатия `"` дают:

```text
"
первая строка
вторая строка
"
```

затем:

```text
""
первая строка
вторая строка
""
```

и затем Python-совместимый строковый блок:

```python
"""
первая строка
вторая строка
"""
```

Чтобы закончить повторное оборачивание, нажмите `Esc`.

Стандартные команды `nvim-surround` `ys`, `ds` и `cs` продолжают работать.

## Русская раскладка

В Normal и Visual mode русские физические клавиши преобразуются в
соответствующие английские команды.

Примеры:

```text
пв          → gd
нн          → yy
ц           → w
Space ы к   → Space s r
```

Пользовательские Ctrl-сочетания также продублированы:

```text
Ctrl+А → Ctrl+F
Ctrl+И → Ctrl+B
Ctrl+З → Ctrl+P
Ctrl+Ц → Ctrl+W
Ctrl+У → Ctrl+E
Ctrl+Т → Ctrl+N
Ctrl+В → Ctrl+D
```

Таким образом, для большинства команд переключаться на английскую раскладку
не требуется. Передача модифицированных Unicode-клавиш зависит от терминала,
поэтому редкие сочетания могут требовать английскую раскладку, если терминал
не различает соответствующий сигнал.

## Терминалы

Нижний и плавающий терминалы используют постоянные буферы. При скрытии
окно закрывается, но shell-процесс продолжает работать, поэтому текущий
каталог, запущенные команды и вывод сохраняются.

Нижний терминал также запоминает высоту, установленную вручную. После
закрытия и повторного открытия через `Ctrl+\`` он восстанавливает последний
размер окна.


| Сочетание | Режим | Действие |
|---|---|---|
| `Ctrl+\`` | Normal или Terminal | открыть или закрыть нижний терминал |
| `Ctrl+E` | Normal или Terminal | открыть или закрыть терминал справа |
| `Ctrl+Shift+T` | Normal или Terminal | показать или скрыть один плавающий терминал с сохранением сессии |
| `Space tt` | Normal | показать или скрыть тот же плавающий терминал |

Повторное нажатие открывает тот же терминал с сохранённой сессией.

## Поиск в текущем файле

`Ctrl+F` открывает стандартный поиск Neovim в текущем файле из Normal,
Insert и Visual mode.

Последовательность работы:

1. нажмите `Ctrl+F`;
2. введите искомый текст после `/`;
3. нажмите `Enter`;
4. используйте `n` для следующего совпадения;
5. используйте `N` для предыдущего совпадения;
6. нажмите `Esc`, чтобы отменить ввод поиска.

Из Insert и Visual mode Neovim сначала возвращается в Normal mode, после
чего открывает строку поиска.

Terminal mode намеренно не перехватывается: внутри терминала `Ctrl+F`
передаётся запущенной shell-программе.

## Поиск и замена

Для поиска и замены используется **Grug FAR**.

| Сочетание | Область поиска |
|---|---|
| `Ctrl+Shift+F` | Git-проект или каталог текущего файла |
| `Space sr` | Git-проект или каталог текущего файла |
| `Space sf` | только текущий файл |
| `Space sw` | проект со словом под курсором в поле поиска |

Область поиска определяется автоматически:

1. корень текущего Git-репозитория;
2. каталог текущего файла, если Git-репозитория нет;
3. текущая рабочая директория для безымянного буфера.

В окне Grug FAR доступны поля:

```text
Search
Replace
Files Filter
Flags
Paths
```

После заполнения `Search` и `Replace` перейдите в Normal mode и нажмите:

```text
\r
```

Основные действия внутри Grug FAR:

| Сочетание | Действие |
|---|---|
| `\r` | выполнить замену |
| `\s` | синхронизировать все вручную изменённые результаты |
| `\l` | синхронизировать текущую строку |
| `\n` | синхронизировать следующее изменение |

### Конфликт с Ghostty

Ghostty может перехватывать `Ctrl+Shift+F` и `Ctrl+Shift+I`.

Чтобы передавать эти сочетания в Neovim, добавьте в конфигурацию Ghostty:

```ini
keybind = ctrl+shift+f=unbind
keybind = ctrl+shift+i=unbind
```

Функции Ghostty можно перенести:

```ini
keybind = ctrl+alt+f=start_search
keybind = ctrl+alt+i=inspector:toggle
```

## Быстрые заметки

Постоянные заметки находятся в:

```text
~/Workspace/notes
```

Структура:

```text
~/Workspace/notes/
├── draft.md
└── inbox/
    └── YYYY-MM-DD_HH-MM-SS_название.md
```

### Сочетания и команды

| Сочетание | Команда | Действие |
|---|---|---|
| `Space nd` | `:Draft` | открыть постоянный `draft.md` |
| `Space nn` | `:Note` | создать новую заметку |
| `Space nf` | `:Notes` | найти заметку через Telescope |
| `Space ns` | `:Scratch` | открыть временный Markdown-буфер |
| `Space nc` | `:ClipEdit` | отредактировать системный clipboard |

### Draft

Команда:

```vim
:Draft
```

открывает:

```text
~/Workspace/notes/draft.md
```

### Создание заметки

```vim
:Note Название заметки
```

создаёт файл в `~/Workspace/notes/inbox`.

Без аргумента:

```vim
:Note
```

Neovim запросит название интерактивно.

Новая заметка получает заголовок и дату создания:

```markdown
# Название заметки

Создано: 2026-08-02 09:00
```

### Автосохранение

Файлы внутри `~/Workspace/notes` автоматически сохраняются при:

- выходе из Insert mode;
- переходе в другой буфер;
- потере фокуса окном Neovim.

### Scratch

`:Scratch` создаёт временный Markdown-буфер без файла, swap и постоянной
истории undo.

### ClipEdit

`:ClipEdit` загружает системный clipboard в отдельный буфер.

После редактирования выполните:

```vim
:w
```

Текст будет записан обратно в clipboard.

## Форматирование

Форматирование выполняется при сохранении файла. Тайм-аут — 500 мс. Если
formatter отсутствует, используется LSP fallback.

| Тип файлов | Formatter |
|---|---|
| Lua | `stylua` |
| HTML | `prettier` |
| CSS и SCSS | `prettier` |
| JSON | `prettier` |
| Markdown | `prettier` |
| JavaScript и JSX | `prettier` |
| TypeScript и TSX | `prettier` |
| Python | `black` |
| Go | `gofmt` |
| Rust | `rustfmt` |

Проверка Conform:

```vim
:ConformInfo
```

Formatter должен быть установлен в системе и доступен через `$PATH`.

## Markdown и изображения

Изображения из Markdown-ссылок показывает `image.nvim`. По умолчанию изображение
открывается во всплывающем окне, когда курсор находится на строке:

```markdown
![Описание](imgs/example.png)
```

| Сочетание | Действие |
|---|---|
| `Space mi` | включить или выключить изображения Markdown |
| `Space mI` | открыть диагностический отчёт `image.nvim` |

Для Markdown используется `render-markdown.nvim`, который улучшает
отображение заголовков, списков, таблиц, блоков кода и чекбоксов.

Для изображений используется `image.nvim`:

```lua
backend = "kitty"
processor = "magick_cli"
```

Для обработки изображений нужен ImageMagick:

```bash
magick --version
```

## Кэш Base46

Base46 хранит скомпилированные цвета в:

```text
~/.local/share/nvim/base46
```

Конфигурация автоматически восстанавливает кэш, если он отсутствует.

Принудительная пересборка:

```bash
rm -rf ~/.local/share/nvim/base46
nvim
```

## Диагностика

Активный каталог конфигурации:

```vim
:lua print(vim.fn.stdpath("config"))
```

Ожидаемый результат:

```text
~/.config/nvim
```

Текущая тема:

```vim
:lua print(require("nvconfig").base46.theme)
```

Leader и localleader:

```vim
:lua vim.print({
  leader = vim.g.mapleader,
  localleader = vim.g.maplocalleader,
})
```

Все сочетания:

```vim
:Telescope keymaps
```

Общая диагностика:

```vim
:checkhealth
```
